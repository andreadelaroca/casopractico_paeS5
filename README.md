Registro y Consulta de Clientes

Este proyecto consiste en una aplicación de escritorio para registrar la información de los clientes de una empresa y las solicitudes que realizan.

La aplicación permite guardar nuevos clientes, consultar los registros existentes y visualizar sus datos. Fue desarrollada utilizando JavaFX y Scene Builder para crear y manejar las diferentes ventanas del sistema.
